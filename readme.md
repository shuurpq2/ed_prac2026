# Fortran
Фортран (Fortran) - **первый в мире** язык программирования высокого уровня, получивший практическое применение и имеющий компилятор. Он дос их пор жив и всотребован и входит в топ 20 самых популярных языков. 
## Сфера применения
Проектирование авиадвигателей, расчет траекторий космических аппаратов, моделирование климата, ядернаяа физика, квантовая химия и анализ больших массивов данных в суперкомпьютерах.
Спрос на Fortran программистов в мире низкий, но имеется критический дефицит специалистов. Применяется в таких профессиях как
- Физик-исследователь / Физик-ядерщик
- Астрофизик / Астроном
- Вычислительный химик / Биоинформатик
- Метеоролог-разработчик / Климатолог
- Геофизик / Сейсмолог
- Инженер по аэродинамике / Авиаконструктор
- Инженер-гидротехник
- Инженер-проектировщик (автомобилестроение, строительство)
- Специалист по суперкомпьютерным вычислениям
- Разработчик математических алгоритмов
- Программист сопровождения
## Особенности
- Работает так же или даже быстрее, чем код, написанный на c из-за агрессивной оптимизации компилятора
- Встроенная поддержка работы с многомерными массивами и векторными вычислениями
- Статическая типизация
